# 记一笔（MoneyBook）需求分析说明书

> 文档版本：v2.1 ｜ 对应软件版本：记一笔 v2.1.21（最新发布版） ｜ 更新日期：2026-11-02 ｜ 代码仓库：https://github.com/liaoyllv/moneybook

## 1. 项目概述

「记一笔」（MoneyBook）是一款完全本地离线运行的个人记账 Android 应用。用户可高效记录日常收入与支出，并通过分类、账户、账本、双层预算、存钱目标、统计四维穿透图表等多种维度全面掌握个人资产与消费动态。应用**不申请网络权限、不包含任何第三方追踪或广告 SDK**，全部数据完全保存在设备本地，充分捍卫个人财务隐私。

- **开发语言**：Kotlin 1.9.24
- **UI 框架**：Jetpack Compose（Material 3），响应式状态驱动架构
- **本地存储**：Room 2.6.1（SQLite v4）+ DataStore Preferences
- **架构模式**：MVVM + Repository 分层架构 + 3 Tab 紧凑导航（首页、统计、设置）
- **多媒体与反馈**：SoundPool 清脆物理音效 + Vibrator 触感震动反馈 + Coil 本地图片渲染
- **最低系统**：Android 9.0（API 28），深度实测并完美适配现代主流机型（vivo X200 Pro mini / OriginOS 5、小米 HyperOS 等）的大字号与高对比度排版
- **版本演进**：历经 v1.0.0 至 v2.0.0 基础完备版，并在 v2.1.x 系列中完成了重大重构与体验跃迁（v2.1.21 整合账单至首页、全局顶部浮动通知、分类 3x4 高频重构、标签即时联想、统计单屏四维下钻、清脆音效与触感震动、暖色调设计系统及鲨鱼记账全量数据迁移）。

## 2. 功能性需求

| 编号 | 模块 | 功能描述 |
| --- | --- | --- |
| FR-01 | 记一笔 | **全屏紧凑排列与秒开响应**：分类 3x4 紧凑排列，按历史使用频次加权自动前置，展开分类按钮置于第 3 排末尾；金额输入框与支付方式同排并列；日期默认选中当天；更多区域可折叠展开自由备注与图片附件；支持一键快速保存与连续记账 |
| FR-02 | 连续记账 | 新增账单提供「继续记」与「记完了」：前者保存后原地保留类型、分类、账户与日期上下文，自动聚焦金额输入框并清空上一笔附件，适合月底集中补账 |
| FR-03 | 分类管理 | 内置精选收支分类并重构专属拟物 Emoji 图标，支持自定义新增、重命名、删除与长按拖拽重排；内置分类受系统级防误删保护 |
| FR-04 | 分类合并 | 支持将任意两项同类型分类执行合并操作，历史账单自动归属到目标分类，当月分类预算自动累加相加，彻底解决分类冗余问题 |
| FR-05 | 标签系统 | **标签多选与行末即时联想**：在记一笔页面标签第二排行末输入框直接键入新标签，输入过程中自动带出历史已用标签供快捷点选；一笔账单支持绑定多个标签，并完整保留自由文本备注 |
| FR-06 | 账户管理 | 内置现金、微信、支付宝、银行卡等账户，支持自定义增删、排序与独立备注；记账时默认支付方式为支付宝，以行内列表形式快捷点选无需多层弹窗；删除账户自动安全转移关联账单 |
| FR-07 | 多账本 | 支持创建、切换、重命名与删除多套独立账本（如日常、旅行、家庭）；账单数据、预算与统计完全物理隔离；首页顶栏一键切换 |
| FR-08 | 首页账单整合 | **首页与账单深度合并**：取消独立账单 Tab，首页聚合当月总收入/总支出/结余卡片、月度预算进度条、全局关键词搜索框、分类/账户/金额筛选胶囊、按月吸顶分组账单明细；底栏收敛为首页/统计/设置 3 Tab，去除非必要文字，消除点击跳动与过度动画 |
| FR-09 | 统计单屏化 | **统计中心四维单屏穿透**：日期筛选全局置顶，四大分析 Tab（占比、对比、趋势、日历）置于其下：<br>① **占比**：左侧 Donut 环形图，右侧环比与单笔均值，分类明细与标签偏好高度固定超出展开，免滑动一屏尽览；<br>② **对比**：120dp 铺满对称双向柱状图（以日期为中轴对比当月与上月同日），支持日/周/月/年切维保持当前 Tab，全周期累计对比整齐排版；<br>③ **趋势**：110dp 压缩折线图，三大核心 KPI 卡片，单日峰值与消费特征智能解读，无需滑动；<br>④ **日历**：星期栏置顶，月度开销概览（总支出、记账天数、单日最高）挪至日历下方，色块与日期数字优化适配，点击日期下发展示当日账单明细 |
| FR-10 | 支出洞察挖掘 | 引入 IQR（四分位距）算法智能挖掘异常支出候选，分类结合标签进行细分统计下钻，帮助用户精准识别异常开销与支出偏好 |
| FR-11 | 月度预算 | 按「年-月」设置总支出预算，首页进度条显示当月已用与剩余额度；超支时红色高亮预警；预算保存后触发顶部通知并**自动返回上一页**，解决输入法遮挡痛点 |
| FR-12 | 分类预算 | 每个支出分类按月设置独立限额，分类预算页显示已用/剩余/超支进度，首页汇总接近（≥80%）或已超支分类 |
| FR-13 | 周期账单 | 针对房租、通勤、会员订阅、工资等固定收支支持每周/每月/每年自动记账；打开应用自动补记到期账单，月末与闰年边界精准收敛 |
| FR-14 | 存钱目标 | 设定目标金额与截止日期，自动计算每月需存金额与进度可视化；存入操作自动生成「储蓄」支出账单并计入统计 |
| FR-15 | 账单附件 | 支持每笔账单附加系统相册图片或本地文件；列表缩略图统一置左、金额严格右对齐；编辑页全屏大图预览；附件随加密备份无损打包还原 |
| FR-16 | 应用锁 | 4-6 位数字密码（加盐哈希存储）+ 指纹解锁；切回前台自动锁屏并唤起生物识别；加密备份恢复后自动同步锁状态 |
| FR-17 | 记账提醒 | 每日定时本地通知提醒记账，时间可自定义；WorkManager 后台守护，重启有效；Android 13+ 规范申请通知权限 |
| FR-18 | 数据导出与备份 | ① **加密备份（.mbk）**：ZIP 容器打包账单与附件 → GZIP 压缩 → AES-256-GCM 加密，PIN 派生密钥跨设备可恢复；<br>② **JSON 备份**：通用明文格式全量备份；<br>③ **CSV 导出**：支持按账本导出表格文件，Excel/WPS 即开即用 |
| FR-19 | 外部账单迁移 | 内置第三方账单导入器（如鲨鱼记账等），解析 CSV/Excel 并自动完成收支类型、分类映射、账户匹配与历史日期对齐，一键全量无损迁移本地 SQLite |
| FR-20 | 全局顶部通知 | 统一封装 `TopSnackbarHost` 浮层组件，全局保存、导出、设置反馈均在状态栏下方以优雅半透明圆角胶囊呈现，彻底避免被输入法或底部导航栏遮挡 |
| FR-21 | 音效与触感反馈 | 集成 SoundPool 44.1kHz 清脆按键音效与物理级轻微触感震动反馈，并在设置页提供独立双开关自由控制 |
| FR-22 | 暖色调设计系统 | 全新设计的温暖柔和色彩体系，搭配高对比深色模式，大字号排版下文字不折行、图标不重叠遮挡 |
| FR-23 | 桌面小组件 | Glance 声明式小组件，桌面实时展示本月结余、收支与预算剩余，支持一键直达记账与自动刷新 |
| FR-24 | 首次引导 | 6 页向导式指引（欢迎/账本/分类/预算/安全/完成），引导中创建数据实时入库生效，支持跳过且仅首次启动展示 |
| FR-25 | 关于与开源协议 | 软件信息动态读取 `BuildConfig.VERSION_NAME`；提供 GitHub 开源仓库直达、关于作者卡片与 MIT 开源许可证全文 |

## 3. 非功能性需求

| 编号 | 类别 | 要求 |
| --- | --- | --- |
| NFR-01 | 隐私安全 | 应用未申请 INTERNET 权限，从系统层面杜绝联网可能；零网络请求、零广告 SDK、零数据回传；数据纯本地存储 |
| NFR-02 | 数据可靠性 | 金额以「分」（Long）为单位存储与运算，杜绝浮点误差；日期统一以 epochDay 索引；数据库升级采用真实 SQLite 引擎自动化断言验证 |
| NFR-03 | 现代机型适配 | 最低支持 Android 9.0（API 28），实测适配 Android 15 / vivo OriginOS 5（vivo X200 Pro mini）、小米 HyperOS 3 等主流系统；完美支持大字体与无界屏幕比例 |
| NFR-04 | 单屏操作哲学 | 核心交互（首页账单聚合、记一笔、统计四维视图）均遵循单屏无滑动操作理念，减少无效滑动与手势疲倦 |
| NFR-05 | 响应速度与跟手度 | 主界面 3 Tab 常驻预热秒开无白屏；记账界面后台预热直出；统计图表解耦数据流实现 0ms 视图切换；按键触发 0 延迟音效震动 |
| NFR-06 | 容错与数据安全 | 备份采用标准 AES-256-GCM 加密；删除账本、清空数据等高风险动作具备双重防误触二次确认；分类合并支持预算自动累加保全 |
| NFR-07 | 架构可维护性 | 严格遵守 Google 推荐的 MVVM + Repository 架构规范，单一职责、依赖倒置、StateFlow 驱动 UI 渲染 |
| NFR-08 | 自由开源共享 | 基于宽松的 MIT 开源许可证，支持社区二次开发与个性化构建；代码结构整洁、工程配置完备 |
