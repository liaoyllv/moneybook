# 记一笔（MoneyBook）测试方案与测试用例

> 文档版本：v2.1 ｜ 对应软件版本：记一笔 v2.1.21（最新发布版） ｜ 更新日期：2026-11-02 ｜ 代码仓库：https://github.com/liaoyllv/moneybook

## 1. 测试方案与质量保证

### 1.1 测试目标
全面验证「记一笔」在架构重构（v2.1.21）后的功能完整性、单屏自适应交互、多机型大字体显示兼容性、极端输入容错、离线数据绝对安全及真实硬件反馈表现。

### 1.2 测试层次与策略

| 层次 | 检验手段 | 核心覆盖目标 |
| --- | --- | --- |
| L1 静态与类型核验 | Kotlin 编译期类型推断 + Room KSP SQL 预编译校验 | 确保全 DAO SQL 语法合法，实体模型与数据库 DDL 严格一致 |
| L2 数据迁移自动化测试 | 基于真实 SQLite 引擎（sqlite-jdbc）执行数据库测试 | 验证 v1→v4 多次迁移的字段类型、默认值、外键约束与数据完整性（33 项自动化断言全部通过） |
| L3 产物规约与签名验证 | aapt2 与 apksigner 命令行自动化审查 | 验证 APK 包名、版本信息（versionCode 42 / versionName 2.1.21）、权限清单（绝对零 INTERNET 权限）及 V2+V3 签名合规性 |
| L4 核心机型真机测试 | 真实物理设备（vivo X200 Pro mini / Android 15 / OriginOS 5，大字体模式） | 首页账单合并、单屏不滑动体验、顶部通知避让键盘、物理按键清脆音效与触感震动、分类合并与鲨鱼记账数据导入 |
| L5 回归质量防护 | 每次版本构建前执行全量冒烟与功能回归 | 杜绝历史功能回退与样式遮挡 |

### 1.3 测试执行环境

| 设备 / 环境项 | 详细配置说明 |
| --- | --- |
| **物理真机 A** | **vivo X200 Pro mini**（Android 15，OriginOS 5.0），测试大字体排版与全面屏手势 |
| **物理真机 B** | **小米 13 / HyperOS 3.0**（Android 15），测试系统权限申请与深色模式 |
| **编译构建链** | JDK 17 + Gradle 8.9 + AGP 8.5.2 + compileSdk 34 + Kotlin 1.9.24 |
| **数据引擎** | SQLite 3.45.1.0（与 Android 系统底层 SQLite 严格对齐） |
